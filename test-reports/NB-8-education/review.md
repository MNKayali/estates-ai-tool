# Review — NB-8-education

Live report: https://www.projento.co.uk/report/2fbccc9cc7ae4100 (12 pages)

Verdict: the programme logic is good: it answers the Q6.1 question clearly ("not achievable, ~30 weeks late"). Cost is about 35–50% too high for a primary school, driven by the New-build element rates, and that turns a reasonable £13m budget into a £4.6m "shortfall".
