# RF-5 — Conversion of a former bank branch to retail, Liverpool

## Story
An independent retailer has taken a 20-year lease on a vacant former bank branch on a Liverpool high street, empty since the bank closed it three years ago. The unit still has the bank's security screens, strongroom and back-office cellular layout, none of which suit a modern retail fit-out — the landlord's agent has already flagged that a change-of-use application will be needed. The retailer wants an open sales floor, a small stockroom and updated services throughout, and needs a costed feasibility case before they commit to the lease's fitting-out period. No formal budget has been fixed yet — the retailer is waiting on this report before setting one.
