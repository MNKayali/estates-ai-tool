# Review — FO-3-hospitality

Verdict: Scope, risk register, phasing and the absence of a budget/target-date verdict (both correctly left out since Q4.3 and Q4.1 were blank/"No specific deadline") are all handled correctly, but the report has one high-impact data bug — postcode BS1 (Bristol) wrongly defaults to a West Midlands location factor instead of South West — plus a mismatched cost build-up label, two untracked standards selections, and a missing Financial Case section despite a financial benefit being given.

## Issues
| # | Severity | Category | Page | Report says | Expected (scenario) | Issue |
|---|---|---|---|---|---|---|
| 1 | High | Region | 1, 2, 4, 7, 8 | "West Midlands, BS1"; "BCIS REGION: West Midlands, Location factor 0.94"; risk register and Constraints Summary: "Postcode BS1 did not match any BCIS region; estimate defaults to West Midlands factor 0.94" | BS1 is Bristol (South West) | BS1 is an unambiguous, well-known Bristol postcode district and should match the South West BCIS region. Instead it fails to match at all and falls back to West Midlands, which is the wrong region for this site and skews every location-adjusted rate across the ~£5.4m-£8.5m estimate. The report is transparent about the mismatch throughout (risk register, constraints, cost assumptions, recommendation 5), but the underlying postcode lookup itself needs fixing. |
| 2 | High | Cost | 7 | "How the percentages were set" → "Preliminaries 9%: 8% base, plus 0.5% for restricted working hours, 0.5% for programme duration > 18 months." | Q3.5 Access constraints: "Scaffold licence or highway encroachment required" | "Restricted working hours" is not the access constraint given for this project — that answer belongs to a different option (compare FO-2, where the same label correctly appears only when Q3.5 = Restricted working hours). This looks like the wrong percentage-rule condition fired — the same "general pattern shadows specific" failure mode this codebase has fixed elsewhere — and it undermines the build-up trace's purpose of showing exactly why each percentage was applied. |

The section should still appear, presumably without a payback figure since Q5.2 was left blank, but it is missing entirely. |
